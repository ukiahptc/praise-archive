# 아이콘

`icon.svg` 가 원본 도안이다. 512×512 기준으로 그려져 있고,
네이비 바탕(#20243F 계열) + 브라스 8분음표 + 옅은 오선 구성이다.

PNG 여섯 개는 이 SVG에서 뽑은 것이다.

| 파일 | 용도 |
|---|---|
| `Icon-180.png` | 아이폰 홈 화면 (apple-touch-icon) |
| `Icon-192.png` · `Icon-512.png` | PWA 설치 아이콘 |
| `Icon-maskable-192.png` · `Icon-maskable-512.png` | 안드로이드 적응형 아이콘. 그림을 20% 안쪽으로 넣어 원형으로 잘려도 안 잘린다 |
| `favicon.png` | 브라우저 탭 (64×64) |

## 다시 뽑는 법

`icon.svg` 를 고친 뒤, 브라우저에서 SVG를 캔버스에 그려 각 크기로
`toDataURL('image/png')` 하면 된다. 마스커블은 그림 묶음을 0.80배로
축소해서 그린다.

## 주의

아이폰은 홈 화면에 추가할 때 아이콘을 한 번 복사해 간다. 아이콘을
바꿔도 **이미 추가해 둔 사람의 홈 화면 아이콘은 그대로다.**
바뀐 아이콘을 보려면 기존 아이콘을 지우고 다시 추가해야 한다.
